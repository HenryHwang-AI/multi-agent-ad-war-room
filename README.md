# 多 Agent 投放作战室

面向 AI 产品经理作品集的离线交互演示。一条投放简报依次经过洞察官、创意官、人工闸门、合规官和分析官，最后收成可以导出的任务包。

品牌、样本、检索数字和价格全部是虚构的。页面不请求网络，也不需要密钥。

## 打开

用浏览器直接打开根目录的 `index.html` 即可。

如果希望导出按钮和剪贴板在本地更稳定，也可以起一个静态服务：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

可选自检（只校验合成数据和处置规则，不参与页面运行）：

```bash
node scripts/check-model.js
```

## 建议演示路径

大约三分钟，用澄光护肤讲回环。

1. 选中「澄光护肤 · 屏障修护精华」。这条被标成适合演示回环。
2. 先不要打开注入，点「启动任务」。看洞察官把假设分成测量和推断，再看创意初稿。
3. 在人工闸门选择「要求修改」。备注可以留着默认那句，也可以改成自己的话。修订稿只会替换越线的句子。
4. 批准。合规官以「条件通过」记下观察项，分析官给出 A/B。底部出现任务包，可以复制或导出 Markdown。
5. 点重置。打开「注入合规失败」，再启动。这次在闸门直接批准初稿。
6. 合规驳回，状态回到创意。修订之后会再请你批准。第二次审查通过。账本里洞察官只有一行，合规官有两行。
7. 拉到「产品判断」，用同一套常数讲多 Agent 的成本和闸门位置。

快进只缩短动画，不改账本里的模型时间。系统若开启「减少动态效果」，页面会去掉动效，步骤仍会走完。

## 你看到的系统

| 角色 | 做什么 | 不做什么 |
| --- | --- | --- |
| 编排器 | 迁移状态、记轨迹和账本 | 不写文案 |
| 洞察官 | 产出标了测量或推断的假设 | 不写口号 |
| 创意官 | 基于假设写角度 | 不自判合规 |
| 人工闸门 | 批准方向，或退回修改 | 不跳过合规，不投放 |
| 合规官 | 引用原句，按阈值处置 | 不改预算 |
| 分析官 | 设计可以停下来的实验 | 不新增强承诺 |

状态机：`IDLE → RESEARCH → CREATIVE → HUMAN_GATE → COMPLIANCE → ANALYST → PACK`。

合规驳回时回到创意，再进入人工闸门，不重跑洞察。注入开关不发明新的风险句，只把同一批命中从「观察」升成「驳回」。

## 目录

- `index.html`：页面入口
- `css/warroom.css`：样式
- `js/model.js`：合成简报、费用常数、合规处置
- `js/warroom.js`：状态机、动画和任务包
- `scripts/check-model.js`：数据自检

## 声明

演示里的广告规则是为了讲清产品结构而做的抽象，不是法律意见。任务包不能直接拿去投放。
